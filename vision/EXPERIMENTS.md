# Experiments and paper correspondence

All paths below are relative to `vision/`. Each name denotes an experiment group;
numbered directories `1/`–`20/` denote independent repetitions, not recorded seed values.
The [alias registry](reproduction/experiment_aliases.json) maps every historical
S3Plus run name to its current name. The five supported launch/summary entry points
accept either spelling and write under the current name.

The mapping identifies experiment families, not a claim that every panel can already
be regenerated by one plotting command. The pipeline writes metrics and orderliness

`dots_fullsymm_assoc` keeps a neutral version of its historical name. Its configuration
contains the old `is_pure_assoc` flag, which the current training implementation does
not read. It is the candidate for the all-three-terms comparison, but this correspondence
needs confirmation before labeling a regenerated figure. Renaming did not enable a new loss.

## Training schedules preserved from the original configs

`num_epochs` is the exclusive upper bound of the zero-based training loop.
For example, 50001 preserves epochs 0 through 50000.

| Family | Addition epochs / batch | Subtraction epochs / heads per addition model |
| --- | --- | --- |
| Fixed dots, including symmetry variants | 50001 / 128 | 20001 / 20, except mixed order: 1 head |
| Fixed dots, reconstruction only | 50001 / 128 | 10001 / 20 |
| Eastern and Western tally marks | 50001 / 128 | 20001 / 20 |
| Multi-style, ELPIS / no symmetry / reconstruction only | 10001 / 256 | 1001 / 1 |
| Multi-style, full-data ceiling | 5001 / 256 | 1001 / 1 |
| Online blur, all four models | 4001 / 128 | 801 / 10 |

All additions use learning rate 0.0001; subtraction uses 0.001. Read the configs
for checkpoint and logging intervals. The current evaluation pipeline reads head
1 only for subtraction; its 20-value summary is not a summary over every trained head.

## Icon alignment

[icon_alignment](LM_align/exp/icon_alignment/config.py) corresponds to main-text
Fig. 4 and Supplementary Table S2 / Fig. S11. It trains 20 projectors for 30 epochs,
using frozen DINO features and the bundled `dots_elpis/1/checkpoint_48000.pt`.
Training, seen-icon evaluation and unseen-icon evaluation images are synthesized online.

`LM_align/statistic_batch.py` currently selects the best training-accuracy epoch
(excluding epoch 0) and summarizes all 20 runs. The paper's converged-run filter and
three-group Table S2 export are not implemented by this entry point.

## Coverage boundaries

- Fig. 2B's resampled training-ratio sweep is not among these 24 configs.
- Random-representation / random-guess baselines are not wired into the documented workflow.
- Historical HM/DM, sampling and subtraction-summary conventions are preserved by
  the naming refactor. Their alignment with the manuscript is a separate pending task.
- The four excluded Mahjong runs are not part of this release.
